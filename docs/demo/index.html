Scenario (Chronological)

Phase 1: Initial Trust Deposit + Immediate Payment

Each account receives a lump-sum Rs 300 trust deposit (simulating an employer/family contribution), immediately followed by a Rs 300 payment to NHIL health insurance (MCC 8062).

Since the others pool has exactly Rs 300, the payment is fully covered from the others pool — zero self-contribution required.

For both accounts, one deposit pair per minute for 30 minutes:

Key Behaviours Demonstrated

  1. Funding source differentiation — Self (auto-detected from origin bank), trust, and third-party deposits are tracked separately and routed to the correct pool.
  2. Others-first payment splitting — Payments drain the others pool (trust + third-party) before touching the self pool, maximising use of contributed funds.
  3. MCC validation — All payments go to MCC 8062 (hospitals), within the allowed set for health-purpose accounts. The allowlist also covers doctors, pharmacies, labs, and insurance premiums (MCCs 6300, 5960).
  4. Double-entry integrity — Every deposit creates a transfer from a sentinel funding source to the PBA pool. Every payment transfers from the PBA pool to merchant settlement. The system always balances.
  5. Multi-source others pool — Account 2 shows trust and third-party funds co-existing in the same others pool, both consumed before self funds.
  6. Tangible benefit of contributions — Account 2's four third-party deposits (Rs 20) directly preserved Rs 20 in the holder's self pool.
